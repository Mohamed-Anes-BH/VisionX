\section{Validation et Analyse des Contrats Officiels de l'Enseignant}
L'analyse des trois documents contractuels fournis par l'enseignant valide formellement les règles suivantes :

\subsection{1. Contrat d'Intégration (AGENT\_INTEGRATION\_CONTRACT.docx v1.0)}
\begin{itemize}[leftmargin=*, itemsep=1.5pt]
    \item \textbf{Indépendance :} L'agent est un service autonome exposé via HTTP et packagé sous Docker. Aucun appel direct entre agents n'est autorisé.
    \item \textbf{Isolation Multi-Tenant :} Chaque requête transmise par le noyau fournit l'en-tête \texttt{X-Tenant-Id} et le jeton \texttt{Authorization: Bearer <tenant\_api\_key>}.
    \item \textbf{Enveloppe Standard Strictement Obligatoire :} Tout endpoint doit renvoyer \texttt{\{"status": "ok"|"error", "data": \{...\}|null, "error": "msg"|null\}}.
    \item \textbf{Les 5 Endpoints Obligatoires :} \texttt{GET /health}, \texttt{POST /tenant/activate}, \texttt{POST /tenant/deactivate}, \texttt{GET /tenant/\{tenant\_id\}/status}, \texttt{GET /config-schema}.
    \item \textbf{Endpoint de Consommation du Bus :} \texttt{POST /exchange/notify} (obligatoire car notre agent consomme des commandes).
\end{itemize}

\section{Modèle de Données Interne \& Isolation Multi-Tenant}
L'agent VisionX implémente les entités suivantes, strictement cloisonnées par \texttt{tenant\_id} :
\begin{enumerate}[leftmargin=*, itemsep=1.5pt]
    \item \textbf{TenantConfig :} \texttt{tenant\_id}, \texttt{tenant\_api\_key}, \texttt{seuil\_qualification\_lead} (défaut : 70), \texttt{auto\_email\_bienvenue} (bool), \texttt{date\_activation}.
    \item \textbf{Prospect :} \texttt{id\_prospect}, \texttt{tenant\_id}, \texttt{nom}, \texttt{email}, \texttt{score\_interet}, \texttt{statut} (nouveau, qualifié, converti).
    \item \textbf{CommandeConsommee :} \texttt{numero\_commande}, \texttt{tenant\_id}, \texttt{client\_email}, \texttt{montant\_total\_ht}, \texttt{statut}, \texttt{date\_reception}.
    \item \textbf{CampagneExecution :} \texttt{id\_execution}, \texttt{tenant\_id}, \texttt{type\_campagne} (onboarding, relance, lead\_nurturing), \texttt{destinataire}, \texttt{timestamp}.
\end{enumerate}
